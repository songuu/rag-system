## 原因

修复前同一问题两次从首页返回“无法从现有知识库中找到答案”或“无法提供答案”。服务端拒答策略处于 shadow，决策为 `sufficient_evidence`、`abstain: false`，上下文未截断；整体拒答来自生成模型。实际 Ollama 上下文长度为 8192。

三条候选中，只有 `codex-local-graph-black-death-e2e-20260908.txt` 与问题相关，重排分数约 0.944；另两条契丹史料分数约 0.0001 和 0.000067。相关原文支持欧洲人口锐减、劳动力短缺、议价能力及社会冲突等事实，却没有提供东西欧差异的完整依据。候选数量不能代表问题覆盖完整。

仅加强提示词仍会出现整体拒答、遗漏编号、把欧洲一般事实归为西欧特有影响、选择无关史料等情况，因此最终实现使用可校验的覆盖判断和原文回答。

## 最终行为

- 可信回答规则作为系统消息，与用户问题及不可信检索材料分开。
- 比较题先使用 JSON schema 判断 `complete / partial / none`，并选择实际提供的来源编号。编号必须在允许名单内，不能从候选条数推定答案。
- 当所有重排分数都位于 0 到 1 时，低于 0.001 的近零相关候选不进入比较覆盖评估；评分缺失或超出该范围时保持原有选择路径。该筛选限定于比较题。
- 完整覆盖走正常生成；部分覆盖由服务端引用选中原文并说明比较缺口；没有相关事实时保留拒答。部分回答保留原文地域范围，避免生成模型补造地区归属。
- 覆盖判断和生成共用原有生成时限及取消信号；提示词版本已更新，新增回归已加入现有测试入口。
