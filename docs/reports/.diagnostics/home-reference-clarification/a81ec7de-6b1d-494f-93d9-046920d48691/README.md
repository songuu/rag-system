# 首页指代澄清与回答语言验证

真实 localhost:3000 首页，启用 Agent 后逐项提问，未模拟服务响应。

根因：当前首页只提交当前问题，不携带对话历史；裸代词被送入向量检索。Agent 的英文系统提示缺少明确的用户语言与直接答复约束，最后一条模型消息直接作为答案展示。

修复：对没有明确主体的短追问先请求澄清，跳过语义分类模型、嵌入、检索与 Agent；保留具名问题的知识库路径。Agent 增加用户语言、中文答复、只输出最终答复和指代澄清约束，并提升相关提示词版本。

本次未接入完整的多轮历史与指代消解；不会根据相似材料猜测前文人物。

| 首页问题 | 实际结果 | 浏览器提交至显示耗时 |
| --- | --- | --- |
| 他是谁 | 澄清，不调用模型/检索 | 10041ms |
| 它有哪些事迹 | 澄清，不调用模型/检索 | 258ms |
| 它死在哪里 | 澄清，不调用模型/检索 | 75ms |
| Who is he? | 澄清，不调用模型/检索 | 57ms |
| 根据知识库资料，契丹人主要分布在哪些地区？ | Agent 检索并用中文直接答复 | 3031ms |

首个请求包含开发环境编译耗时；后三个澄清请求均无模型与嵌入调用、无证据、无工作流。明确主体的中文问题检索到启用的 EPUB 证据，并显示中文答复。原有文档状态未改动。

290 项测试使用相同断言串行通过。并行复核时两项已有持久化用例失败，其根因未独立确认。类型检查与本次生产代码 ESLint 检查通过。

原始响应仅保留在临时目录；仓库记录不包含定位令牌或密钥。
