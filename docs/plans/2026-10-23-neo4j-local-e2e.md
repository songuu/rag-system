# 本地知识图谱聊天启用与真实端到端验证

用户授权补齐本地启用配置，并使用现有知识图谱验证普通聊天实体查询、两跳关系解释及点击原文依据。沿用权威 Sprint 的 Work 阶段，不替换 pointer，不将本地验证记为生产门禁完成。

- [ ] L1：核实现有服务、图谱发布状态与原始文档映射，选择可核验的真实两跳路径。
- [ ] L2：最小补齐本地配置、稳定引用密钥及必要的本地发布/映射前置，保留恢复信息。
- [ ] L3：启动或复用本地应用，通过真实 HTTP 验证实体/两跳问题和原文预览。
- [ ] L4：通过真实聊天页面提交上述问题，点击引用，核对原文和每条关系来源。
- [ ] L5：复核变更及真实证据，补充启用/复现说明与明确的验证边界。

不提交或推送，不改生产开关，不删除现有图谱/卷/文档。密钥、token、locator 和真实原文不进入普通报告或 Git；本地真实证据放在确认被忽略的目录。不能以合成 API、测试图谱或关闭来源校验代替本次验收；如旧图谱缺少原文映射，必须核实并通过现有正式流程补齐，不能伪造 ready 状态或直接修改 pointer/outbox。
