## 一、训练任务概述

### 1.1 任务目标
本训练旨在构建一个能够准确回答欧洲中世纪历史问题的RAG系统。系统需要从专业历史文献中检索相关信息，并生成连贯、准确的回答。

### 1.2 训练数据特征
- 源文档：15世纪欧洲历史文献集（数字化版本）
- 文档数量：342篇
- 总词数：约120万词
- 时间跨度：公元476年（西罗马帝国灭亡）至1492年（哥伦布发现新大陆）
- 语言：英文（现代英语翻译版）
- 主题分布：
  - 政治制度：28%
  - 宗教发展：22%
  - 社会经济：19%
  - 战争与冲突：18%
  - 文化艺术：13%

## 二、文档处理与索引构建

### 2.1 文本预处理示例

**原始文本片段（来源：《法兰克王国编年史》，约撰写于9世纪）：**
```
"Carolus Magnus, Rex Francorum, imperator augustus, anno Domini DCCC, 
in urbe Roma a pontifice Leone tertio coronatus est. Post hoc, multas 
leges emendavit et scholam palatinam condidit."
```

**预处理后：**
```
段落ID：FRANK_009_para_015
内容：查理曼大帝，法兰克国王，尊贵的皇帝，于公元800年在罗马城
由教皇利奥三世加冕。此后，他修订了许多法律并建立了宫廷学校。
元数据：{“文档来源”："法兰克王国编年史"，"撰写时间":"9世纪"，
"地理位置":"西欧"，"主题":["加冕典礼","法律改革","教育"]}
嵌入向量维度：768
```

### 2.2 分块策略
- 块大小：256个标记（tokens）
- 重叠：32个标记
- 分块方法：语义边界感知分块（优先在段落边界处分块）

### 2.3 向量数据库索引
```
索引配置：
- 嵌入模型：all-mpnet-base-v2
- 向量维度：768
- 索引类型：HNSW（分层可导航小世界图）
- 相似度度量：余弦相似度
- 索引参数：{“M”：16，“ef_construction”：200，“ef_search”：50}
- 总索引文档块数：8,957
```

## 三、查询-检索训练示例

### 3.1 训练查询集（部分示例）

| 查询ID | 用户查询 | 难度等级 | 预期检索主题 |
|--------|----------|----------|-------------|
| Q_042 | "查理曼大帝加冕的具体年份和地点是什么？" | 简单 | 加冕典礼、时间、地点 |
| Q_117 | "中世纪采邑制度对农民生活的影响" | 中等 | 封建制度、社会经济 |
| Q_203 | "比较1096年和1202年十字军东征的动机差异" | 困难 | 宗教战争、历史比较 |

### 3.2 检索结果评估标准
```
相关性评分（0-5分）：
0 - 完全不相关
1 - 略微相关，但信息价值低
2 - 部分相关，但缺少关键信息
3 - 相关，涵盖基本事实
4 - 高度相关，包含重要细节
5 - 完美匹配，包含所有必要信息
```

### 3.3 检索优化记录
```

改进措施：增加查询扩展（同义词扩展）
效果评估：
- 平均召回率@5：从0.72提升至0.79
- 平均精确率@3：从0.68提升至0.74
- 平均检索时间：从156ms增加至189ms
```

## 四、生成模块训练

### 4.1 提示工程模板
```
基础模板：
"基于以下提供的上下文信息，请以专业历史学家的身份回答问题。
如果信息不足，请说明哪些方面缺乏足够证据。

上下文：
{context_str}

问题：
{query_str}

回答要求：
1. 首先直接回答问题
2. 引用上下文中的具体证据
3. 如有可能，提供历史背景
4. 指出任何不确定的信息
```

### 4.2 训练数据对示例
```
输入：
{
  "query": "黑死病对中世纪欧洲社会结构产生了什么影响？",
  "retrieved_contexts": [
    "文档ID: PLAGUE_003_para_012: 1347年至1351年间，黑死病导致欧洲人口减少约30-50%...",
    "文档ID: SOC_008_para_007: 劳动力短缺导致农奴制度开始瓦解...",
    "文档ID: ECON_015_para_004: 幸存工人工资上涨了约40-60%..."
  ]
}

目标输出：
"黑死病对中世纪欧洲社会结构产生了深远影响。首先，1347-1351年间的人口大幅减少（30-50%）导致劳动力严重短缺。这直接引发了经济结构变化：幸存工人的工资上涨了40-60%，增强了他们的议价能力。社会层面上，传统的农奴制度开始瓦解，因为地主不得不提供更好的条件以留住劳动力。这些变化为后续的社会变革和文艺复兴奠定了基础。需要注意的是，不同地区受影响程度有所差异，西欧某些地区的社会变革比东欧更为显著。"
```

### 4.3 生成质量评估指标
- 事实准确性：0-5分（基于历史事实核对）
- 信息完整性：0-5分（是否涵盖所有关键点）
- 逻辑连贯性：0-5分（论证是否合理）
- 引用适当性：0-5分（是否准确引用上下文）
- 幻觉检测：是否存在未基于上下文的虚构信息

## 五、端到端测试案例

### 5.1 测试案例 #7
```
用户输入：
"请解释‘神圣罗马帝国’为什么被称为‘既不神圣，也不罗马，更非帝国’？"

系统检索到的前3个相关文档块：
1. HRE_012_para_004: "伏尔泰在《风俗论》中的著名评论..."
2. HRE_005_para_011: "神圣罗马帝国的实际权力结构分析..."
3. HRE_009_para_008: "帝国与罗马教廷关系的复杂性..."

系统生成回答：
"这句话源于法国哲学家伏尔泰在18世纪的批评。首先，‘不神圣’指的是帝国后期与罗马教廷的频繁冲突，特别是在叙任权斗争中表现出的世俗化倾向。其次，‘不罗马’是因为帝国核心区域主要在德意志地区，而非意大利的罗马。最后，‘非帝国’批评其权力分散，中央集权薄弱，皇帝实际控制范围有限，更像是诸侯联盟。这一评论反映了启蒙运动时期对中世纪制度的批判态度。需要说明的是，这一评价主要适用于帝国后期（17-18世纪），早期情况有所不同。"

评估结果：
- 事实准确性：5/5
- 信息完整性：4/5
- 逻辑连贯性：5/5
- 引用适当性：4/5
- 幻觉检测：无幻觉
- 综合评分：4.5/5
```

### 5.2 失败案例分析
```
案例ID：FAIL_023
用户查询："中世纪城堡的厕所系统如何工作？"
问题：检索系统返回了关于城堡建筑和防御系统的文档，但缺少卫生设施的具体信息。
根本原因：源文档集中关于日常生活的细节较少，偏向政治军事史。
解决方案：1) 扩展源文档范围；2) 添加相关实体识别以改进检索。
```
